## The line

> ERROR 04: I have stopped mid-cycle. One sock is missing. I know where it is. I am not telling you.

A washing machine, flat and put-upon: it stopped mid-cycle, it knows exactly where your sock went, and it is keeping that information to itself. The laugh comes from the truth of the fault — washers really do eat socks — not from a pun bolted on.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`, byte-identical on every run. The program is Python 3.13, stdlib only, deterministic and offline, and refuses to write a line outside 1–200 characters.
